# JobTracker 화면 목업

2026-10-03에 보관한 화면 초안입니다. 실제 화면 구현 시 배치와 동작을 참고합니다.

## 열기

- [목업 열기](jobtracker-flow.html): 파일을 내려받거나 탐색기에서 더블클릭하면 브라우저로 볼 수 있습니다.
- [편집용 원본](jobtracker-flow.fragment.html): 대화에서 확인한 목업의 HTML 원본입니다.

예시 데이터로 동작하며 서버와 DB에는 연결하지 않습니다. 목업의 등록·수정·삭제·상태 변경은 실제 데이터에 영향을 주지 않습니다.

## 화면 동작

1. 회사 목록에서 회사 이름과 위치를 확인합니다.
2. 같은 화면에서 해당 회사의 지원내역을 펼쳐봅니다. 목업은 상세보기 버튼을 사용하고, 실제 화면은 회사 이름을 누르는 HTML `<details>`·`<summary>` 방식입니다.
3. 지원내역에는 직무, 지원 날짜, 메모, 지원 상태를 표시합니다.
4. 상태 드롭다운에서 선택하면 별도 저장 버튼 없이 변경합니다.
5. 회사와 지원내역을 각각 등록·수정·삭제할 수 있습니다.
6. 지원내역 등록 시 날짜는 오늘로 표시하고, 과거 날짜로 바꿀 수 있게 합니다.
7. 회사 삭제 시 확인 문구를 표시합니다. 지원내역이 있으면 함께 삭제됨을 알리고 취소 또는 삭제를 선택하게 합니다.

## 실제 화면을 만들 때 반영할 사항

- **‘지원내역’ 제목과 첫 지원내역 사이의 구분선은 실제 화면에 반영했습니다.** 보관한 목업에는 아직 반영하지 않았습니다.
- 목업은 이 정도에서 보관하고, 실제 화면을 만들면서 간격·색상·사용상의 불편을 다듬습니다.
- 실제 화면은 회사 등록 API 연결과 Mustache 회사별 지원내역 출력을 구현했습니다. 다음은 지원내역 등록 입력 화면을 기존 API에 연결합니다. 상태 선택·수정·삭제 화면은 후속 작업입니다.

목업에서 동작하는 기능이 실제 서버에도 모두 구현되었다는 뜻은 아닙니다. 실제 구현 여부는 코드와 API 테스트로 확인합니다.
